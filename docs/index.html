              How it works

              Write the spec

              Rooms as rectangles in feet, doors and windows by wall and offset. A person or an AI can write it; it's plain text you can read and check.

              Gate it

              Room sizes and bedroom egress are checked against code minimums before anything is drawn. Tier 1 advises, Tier 2 enforces.

              Solve the geometry

              Walls are polygon math: offsets, unions and openings in feet. No model touches the drawing. Same input, identical geometry.

              Prove it

              A SHA-256 fingerprint of the walls is recorded every run. Change nothing and it never changes. The DXF opens in free QCAD or any CAD.
